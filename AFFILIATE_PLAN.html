📋 Overview

This plan outlines the implementation of a complete affiliate system for your booking application. Each location will have its own affiliates who can promote the business, track their referrals, and earn commissions on successful bookings.

What This System Does

  • Affiliates can log in and view their unique QR code
  • QR codes can be printed for physical distribution
  • Customers scanning the QR code get a discount
  • Affiliates earn commission on each booking
  • Admins and Location Managers can manage affiliates and view earnings

🗄️ Database Schema

1. Update Staff Role

Add 'affiliate' to the existing role check constraint in the staff table.

2. New Table: affiliate_profiles

CREATE TABLE affiliate_profiles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  staff_id UUID NOT NULL REFERENCES staff(id) ON DELETE CASCADE,
  location_id UUID NOT NULL REFERENCES locations(id),
  affiliate_code VARCHAR(20) UNIQUE NOT NULL,  -- e.g., "LOC1-AFF123"
  commission_type VARCHAR(20) DEFAULT 'percentage',  -- 'percentage' or 'fixed'
  commission_rate DECIMAL(10, 2) DEFAULT 10.00,  -- 10% or $10
  discount_type VARCHAR(20) DEFAULT 'percentage',
  discount_value DECIMAL(10, 2) DEFAULT 5.00,  -- customer discount
  total_earnings DECIMAL(10, 2) DEFAULT 0,
  total_bookings INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

3. New Table: affiliate_referrals

CREATE TABLE affiliate_referrals (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  affiliate_id UUID NOT NULL REFERENCES affiliate_profiles(id),
  booking_id UUID REFERENCES bookings(id),
  customer_id UUID REFERENCES customers(id),
  booking_amount DECIMAL(10, 2),
  discount_given DECIMAL(10, 2),
  commission_amount DECIMAL(10, 2),
  status VARCHAR(20) DEFAULT 'pending',  -- pending, confirmed, paid, cancelled
  created_at TIMESTAMPTZ DEFAULT NOW()
);
