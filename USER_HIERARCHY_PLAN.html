Role Definitions & Responsibilities

Role DB Value Reports To Primary Responsibilities Dashboard Access
Admin admin None (Top Level) Full system control, manage all locations, staff, settings /dashboard (Full Access)
Location Manager location_manager Admin Manage assigned location, oversee front desk & captains, view reports /dashboard (Location Scoped)

Captain captain Location Manager View assigned trips, check-in guests, manage trip logs /captain

Login Page Role Selection (5 Options)

Users select their role type on the login page. Server validates the role after authentication.

👑 Admin

LoginType: "admin"

Full system administrators with unrestricted access.

  • Validates: role = 'admin'
  • Redirects to /dashboard
  • Full access to all features

🏢 Location Manager

LoginType: "location_manager"

Managers responsible for specific locations.

  • Validates: role = 'location_manager'
  • Redirects to /dashboard
  • Scoped to their location

💻 Front Desk

LoginType: "front_desk"

Front desk staff handling bookings and customers.

  • Validates: role = 'front_desk'
  • Redirects to /dashboard
  • Bookings & customers only

⚓ Captain

LoginType: "captain"

Boat captains managing their assigned trips.

  • Validates: role = 'captain'
  • Redirects to /captain
  • Trip check-ins & logs

👤 Customer

LoginType: "customer"

Customers viewing their bookings.

  • Validates: customers table
  • Redirects to /account
  • View bookings & waivers

Database Schema Changes

1. Update Role Enum in Staff Table

-- Migration: Update staff role constraint ALTER TABLE staff DROP CONSTRAINT staff_role_check; ALTER TABLE staff ADD CONSTRAINT staff_role_check CHECK (role IN ( 'admin', 'location_manager', -- NEW: replaces 'manager' 'captain', 'front_desk' )); -- Migrate existing managers to location_manager UPDATE staff SET role = 'location_manager' WHERE role = 'manager'; -- Remove guide role DELETE FROM staff WHERE role = 'guide';

2. Create Locations Table & Add Location Scoping

-- Create locations table for multi-location support CREATE TABLE locations ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), name VARCHAR(255) NOT NULL, address TEXT, is_active BOOLEAN DEFAULT true, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Add location_id to staff for scoping ALTER TABLE staff ADD COLUMN location_id UUID REFERENCES locations(id); -- Location managers can only see their location's data -- Front desk & captains inherit location from their manager

3. Add Manager Assignment for Hierarchy

-- Add reports_to column for hierarchy ALTER TABLE staff ADD COLUMN reports_to UUID REFERENCES staff(id); -- Front desk and captains report to a location_manager -- Location managers report to admin (or NULL)
